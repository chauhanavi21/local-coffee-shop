# Site images

All images are **bundled locally** in `public/images/` (24 JPEGs, ~1.2 MB total).

They load from your own server — no Unsplash/Pexels dependency at runtime.

## If you replace images

Drop new files into `public/images/` using the same filenames referenced in `src/data/menu.ts` and page components.
